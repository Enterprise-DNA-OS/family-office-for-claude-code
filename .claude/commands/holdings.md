---
description: Every asset at its latest value, filtered by entity or asset class.
---

Run `npm run family -- holdings [--entity=NAME] [--class=CLASS] --json` and show asset, entity, class, local value, date and base value. Flag any row with no valuation date. Classes: cash, term-deposit, listed, fixed-income, private-equity, venture, property, private-company, collectible, loan, other.
