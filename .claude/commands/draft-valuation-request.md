---
description: A request to a fund manager, valuer or company for an up-to-date value. Draft only.
---

1. Run `npm run family -- stale --json` and `npm run family -- valuations ASSET --json` for the asset.
2. Write the request to `drafts/valuation-request-ASSET-YYYY-MM-DD.md`: the asset, the entity that holds it, the last value and its date, what is needed (a NAV statement, a registered valuation, the board's view of fair value) and by when.
3. Short and polite. No figures beyond the last recorded value. Nothing is sent.
