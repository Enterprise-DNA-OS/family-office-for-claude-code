---
description: A trustee or director approval to pay a capital call, ready to sign. Draft only.
---

1. Run `npm run family -- calls --json` and pick the call the operator means (ask if more than one fits).
2. Run `npm run docs -- capital-call-approval` and give the operator the file for that call under `docs-out/capital-call-approval/`.
3. If the operator wants a covering note, write it to `drafts/capital-call-FUND-YYYY-MM-DD.md`: the call, the due date, the entity paying, its cash, and the uncalled balance after this call.
4. Never pay, schedule or send anything.
